# FiveM Radio System

A complete radio system for FiveM servers with multiple channels and volume control.

## Features

- Multiple radio channels
- Adjustable volume control
- User-friendly UI
- Player preference saving

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files.
2. Place the files in your FiveM server's resources folder.
3. Add `start radio_system` to your server.cfg file.
4. Import the database.sql file into your MySQL database.

## Usage

### Commands

- `/radio` - Open the radio UI

### Keybinds

- `F10` - Open the radio UI

### Permissions

- Players need to be logged in to use the radio system.

## Configuration

The radio system can be configured in the `config.lua` file. You can adjust the radio channels, default channel, and volume settings.
